# ROA 디자인 구조

시각적 방향: ‘스트리트 그래픽과 국제 재난대응기관의 아카이브’. 메인 일러스트 위의 큰 ROA 워드마크, 노란 사선 띠, 번호가 붙은 편집형 카드가 공통 언어입니다. 설정 본문은 읽을 수 있는 폭의 16–17px 문장으로 제공합니다.

| 화면 | 구성 | 모바일 |
| --- | --- | --- |
| 홈 | 일러스트 + 대형 워드마크, 4개 탐색 카드, 축약 연표, 조직 포스터 | 상단 일러스트/하단 카피, 2열 카드 |
| WORLD | 소개·포탈·이상현상, 밝은 연표 지면 | 본문과 연도 세로 배열 |
| ABILITY | 약 2% 대형 숫자, 100칸 중 2칸 강조 | 숫자 중심, 작은 시각화 |
| ALIEN | Acid Green 영문 타이포 지면 | 세 줄 제목과 축약 프레임 |
| RANGER | 복무 카드, 키보드 사용 가능한 등급 탭, 타입별 위험도 | 5개 등급 선택 유지, 사건 설명 아래로 이동 |
| ORGANIZATIONS | 노란 ROA / 공문서형 관리국 / 붉은 ORIGIN 포스터 | 세 조직을 한 장씩 세로 배열 |
| 준비 중 메뉴 | 대형 제목과 Coming Soon 라벨 | 화면 폭에 맞춘 제목 |

공통 부품: Base, Logo, Section, Timeline, Organizations, GradeSystem, IncidentSystem. 신규 문서는 records, 신규 인물은 characters의 공통 템플릿을 사용합니다.

동작: 스크롤 등장, 버튼·카드 hover 이동, 접근 가능한 모바일 details 메뉴, 등급 탭의 좌우/Home/End 키, 지원 브라우저의 페이지 전환. 움직임 줄이기 설정에서는 모션을 해제합니다. 정적 원고는 JavaScript 없이도 존재합니다.
