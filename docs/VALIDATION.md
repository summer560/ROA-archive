# 구현 검증

- Astro 정적 빌드 성공: 홈, 다섯 공개 카테고리, 두 준비 중 메뉴, 404.
- 전체 내부 링크·해시 링크·이미지 경로, 제목·설명·언어 설정 검증 통과.
- 임시 Markdown을 사용해 캐릭터 상세/목록, 추가 설정 상세/카테고리 목록, sitemap 자동 추가를 검증했습니다. 테스트 문서는 최종 소스와 결과물에서 제거했습니다.
- `draft: true`인 문서가 페이지·목록·sitemap에서 제외되는 것을 검증했습니다.
- 데스크톱 1363px 홈에서 이미지 로딩과 가로 넘침이 없는 것을 확인했습니다.
- 390px 및 320px iframe 화면으로 모바일 배치를 확인했습니다. 홈, 레인저 소개, 등급 선택, 조직 포스터, 연표를 확인했습니다. 실제 휴대기기에서의 검증은 별개입니다.
- 등급 3 선택 → 등급 4로 키보드 이동 → 설명 변경을 확인했습니다.
- 모바일 메뉴 열기 및 Escape 닫기를 확인했습니다.
- 초기에 발견한 홈 그라데이션 색상 표기와 워드마크 간격을 수정했습니다.
- Cloudflare Pages의 실제 계정 연결/운영 배포는 아직 수행하지 않았습니다. 설정 방법은 README에 있습니다.

## 후속 수정 검증

- WORLD에서 포탈 독립 항목과 이상현상 내부 규칙이 출력되지 않음을 확인했습니다. 연표는 이후 최신 요청에 맞춰 다시 조정했습니다.
- ROA·ORIGIN 카드 문구와 ARCHIVE·CHARACTERS의 삭제 요청을 반영했습니다.
- 대화 미리보기에서 ALIEN 제목, 정규 복무 카드, 등급 상세 설명, ROA·관리국 카드의 실제 글자 색이 검정으로 적용되는 것을 확인했습니다. ORIGIN은 어두운 배경과 밝은 본문을 유지합니다.
- 등급 1의 설명이 초기 표시되며, 등급 3 클릭 및 오른쪽 방향키로 등급 4의 설명이 표시됨을 확인했습니다.
- 미리보기의 페이지 클래스가 CSS 범위의 루트에 있음을 명시하여 관리국의 밝은 배경과 페이지별 색상이 정상 적용되도록 수정했습니다.
- 390px 미리보기에서 모바일 메뉴 이동과 ALIEN 제목의 대비·가로 넘침을 확인했습니다.

## 밝은 배경의 글자 톤 검토

- ALIEN 첫 화면의 한국어 제목·소개 문단을 제거했으며, 배포 HTML과 메타데이터·미리보기에 두 문장이 남아 있지 않음을 확인했습니다.
- 연표 설명, 관리국 본문과 라벨, 정규 복무 카드의 라벨, 등급 설명 라벨을 검정 또는 짙은 차콜로 조정했습니다. `--text-on-light`와 `--secondary-on-light`에서 관리합니다.
- 브라우저에서 밝은 단색 배경 위에 표시되는 글자의 실제 색상과 배경색을 읽어 대비를 검토했습니다. 장식·이미지 위 글자와 숨겨진 등급 패널은 이 측정에서 제외했습니다.

## 메인 이미지·최신 연표 수정 검증

- 새 첨부 JPG를 1216×832 WebP로 변환하여 기존 메인 이미지 경로에 교체했습니다. 브라우저에서 새 이미지 로딩과 데스크톱·390px 모바일 구도를 확인했습니다.
- 관리국 입장을 “이능력자를 관리해야 할 / 위험 요소로 봅니다.”로 변경했으며, 데스크톱과 390px 화면에서 실제 두 줄로 표시됨을 확인했습니다.
- 홈의 추가 안내 문구를 삭제했습니다. 홈과 WORLD 연표 제목은 #111111, 연표 본문은 #292925로 직접 지정했습니다. 미리보기 CSS도 개별 루트 아래에 명시적으로 적용해 주변 화면의 글자 스타일과 분리했습니다.
- 연표는 1500s—1600s, 1700s—1800s, 1800s—1900s, 1900s—1920s, 1920s, 1940s, 1950s, 1960s의 여덟 항목과 요청된 사건명으로 변경했습니다. 기존 설명을 필요한 항목으로 나누어 배치했습니다. 홈 주요 연표와 WORLD 카드의 연도도 같은 데이터에 연결했습니다.
- 실제 브라우저 DOM에서 여덟 항목과 제목, 모바일 가로 넘침 여부를 확인했습니다. 데스크톱 홈·WORLD 연표 화면도 직접 확인했습니다.
- 배포 ZIP은 완성된 dist 내용만 담고, 압축 최상위에 index.html을 둡니다. Cloudflare 계정 연결과 운영 배포는 별도로 진행합니다.
