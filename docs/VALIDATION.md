# 구현 검증

- Astro 정적 빌드 성공: 홈, 다섯 공개 카테고리, 두 준비 중 메뉴, 404.
- 전체 내부 링크·해시 링크·이미지 경로, 제목·설명·언어 설정 검증 통과.
- 임시 Markdown을 사용해 캐릭터 상세/목록, 추가 설정 상세/카테고리 목록, sitemap 자동 추가를 검증했습니다. 테스트 문서는 최종 소스와 결과물에서 제거했습니다.
- `draft: true`인 문서가 페이지·목록·sitemap에서 제외되는 것을 검증했습니다.
- 데스크톱 1363px 홈에서 이미지 로딩과 가로 넘침이 없는 것을 확인했습니다.
- 390px 및 320px iframe 화면으로 모바일 배치를 확인했습니다. 홈, 레인저 소개, 등급 선택, 조직 포스터, 연표를 확인했습니다. 실제 휴대기기에서의 검증은 별개입니다.
- 등급 3 선택 → 등급 4로 키보드 이동 → 설명 변경을 확인했습니다.
- 모바일 메뉴 열기 및 Escape 닫기를 확인했습니다.
- 초기에 발견한 홈 그라데이션 색상 표기와 워드마크 간격을 수정했습니다.
- GitHub main과 Cloudflare Pages의 자동 배포 연결이 완료되었습니다. 갤러리 추가 커밋의 Cloudflare Pages 배포 성공을 확인했습니다. 설정 방법은 README에 있습니다.

## 후속 수정 검증

- WORLD에서 포탈 독립 항목과 이상현상 내부 규칙이 출력되지 않음을 확인했습니다. 연표는 이후 최신 요청에 맞춰 다시 조정했습니다.
- ROA·ORIGIN 카드 문구와 ARCHIVE·CHARACTERS의 삭제 요청을 반영했습니다.
- 대화 미리보기에서 ALIEN 제목, 정규 복무 카드, 등급 상세 설명, ROA·관리국 카드의 실제 글자 색이 검정으로 적용되는 것을 확인했습니다. ORIGIN은 어두운 배경과 밝은 본문을 유지합니다.
- 등급 1의 설명이 초기 표시되며, 등급 3 클릭 및 오른쪽 방향키로 등급 4의 설명이 표시됨을 확인했습니다.
- 미리보기의 페이지 클래스가 CSS 범위의 루트에 있음을 명시하여 관리국의 밝은 배경과 페이지별 색상이 정상 적용되도록 수정했습니다.
- 390px 미리보기에서 모바일 메뉴 이동과 ALIEN 제목의 대비·가로 넘침을 확인했습니다.

## 밝은 배경의 글자 톤 검토

- ALIEN 첫 화면의 한국어 제목·소개 문단을 제거했으며, 배포 HTML과 메타데이터·미리보기에 두 문장이 남아 있지 않음을 확인했습니다.
- 연표 설명, 관리국 본문과 라벨, 정규 복무 카드의 라벨, 등급 설명 라벨을 검정 또는 짙은 차콜로 조정했습니다. `--text-on-light`와 `--secondary-on-light`에서 관리합니다.
- 브라우저에서 밝은 단색 배경 위에 표시되는 글자의 실제 색상과 배경색을 읽어 대비를 검토했습니다. 장식·이미지 위 글자와 숨겨진 등급 패널은 이 측정에서 제외했습니다.

## 메인 이미지·최신 연표 수정 검증

- 새 첨부 JPG를 1216×832 WebP로 변환하여 기존 메인 이미지 경로에 교체했습니다. 브라우저에서 새 이미지 로딩과 데스크톱·390px 모바일 구도를 확인했습니다.
- 관리국 입장을 “이능력자를 관리해야 할 / 위험 요소로 봅니다.”로 변경했으며, 데스크톱과 390px 화면에서 실제 두 줄로 표시됨을 확인했습니다.
- 홈의 추가 안내 문구를 삭제했습니다. 홈과 WORLD 연표 제목은 #111111, 연표 본문은 #292925로 직접 지정했습니다. 미리보기 CSS도 개별 루트 아래에 명시적으로 적용해 주변 화면의 글자 스타일과 분리했습니다.
- 연표는 1500s—1600s, 1700s—1800s, 1800s—1900s, 1900s—1920s, 1920s, 1940s, 1950s, 1960s의 여덟 항목과 요청된 사건명으로 변경했습니다. 기존 설명을 필요한 항목으로 나누어 배치했습니다. 홈 주요 연표와 WORLD 카드의 연도도 같은 데이터에 연결했습니다.
- 실제 브라우저 DOM에서 여덟 항목과 제목, 모바일 가로 넘침 여부를 확인했습니다. 데스크톱 홈·WORLD 연표 화면도 직접 확인했습니다.
- 배포 ZIP은 완성된 dist 내용만 담고, 압축 최상위에 index.html을 둡니다. Cloudflare 계정 연결과 운영 배포는 별도로 진행합니다.

## 갤러리 및 상호작용 추가 검증

- ARCHIVE를 갤러리로 변경하고 홈의 Coming Soon 안내도 갤러리 링크로 갱신했습니다.
- 원본 JPG는 첨부 파일과 SHA-256이 일치하며 1216×832 크기를 유지합니다. 목록용 WebP와 원본 JPG는 월별 고정 파일명으로 보관합니다.
- 브라우저에서 이미지 확대, 실제 크기 전환, 화면 맞춤, Esc 닫기, 초점 복귀, 스크롤 잠금 해제를 확인했습니다.
- 390px iframe에서 갤러리와 확대 화면의 가로 넘침이 없고 조작 버튼 높이가 44px 이상임을 확인했습니다.
- 연표의 주요 사건용 크기 재정의를 제거했습니다. 320px iframe에서 여덟 연도 모두 32px로 동일하게 표시되고 가로 넘침이 없음을 확인했습니다.
- 읽기 진행 표시와 현재 목차 강조를 추가했습니다. 스크롤은 기본 브라우저 동작을 유지하며 갤러리 진입·확대 모션은 reduced-motion 설정을 따릅니다.

## 갤러리 간소화 및 지부 탭 검증

- 갤러리 화면에서 안내 문장, VISUAL GALLERY, 이미지 번호·제목·크기·포맷을 제거했습니다. 제목은 GALLERY이며 확대 보기와 원본 다운로드 링크를 유지합니다. 변경 후 확대·닫기와 다운로드 파일명 연결을 확인했습니다.
- SDC·특수편성국의 작은 영문 라벨과 한국 지부의 폐기된 신설·개설 표현을 제거했습니다. 나머지 운용 설명은 문단만 나누었습니다.
- 브라우저에서 지부 탭 클릭, 방향키 이동, 기존 목차 링크로 다른 탭 열기를 확인했습니다. 직접 #special-formation 주소로 진입하면 한국 지부가 선택됩니다.
- 390px 모바일 화면에서 두 탭과 본문이 가로로 넘치지 않고, 개요와 상세 본문이 세로로 표시됨을 확인했습니다. 자바스크립트가 실행되기 전에는 두 지부 본문을 모두 표시합니다.
- 하위 페이지의 반복되는 ROA / WORLD ARCHIVE 링크를 제거하고 홈의 브랜드 표시는 유지했습니다.

## 레인저 등록증 콘텐츠 검증

- `/ranger-id/`와 홈·아카이브의 진입 링크를 추가했습니다. 기존 메뉴와 세계관 본문은 유지합니다.
- 데스크톱과 390px 모바일 화면에서 입력·사진·디자인 편집 화면을 확인했습니다. 세로형에서 긴 이능력명과 영문 국가명이 카드 폭 안에 들어가는 것을 확인했습니다.
- JPG 사진 업로드, 사진 좌우 배치, 위치 조절, 흑백 전환, 배경색 프리셋과 자동 글자색을 확인했습니다. 사진과 입력값은 브라우저 메모리에서만 처리합니다.
- 상세 소속 선택 및 생략, Grade 1의 정규 복무 적용, 초기화 및 필수 입력 누락 시 저장 방지를 확인했습니다.
- 브라우저에서 가로형 2400×1512, 세로형 1512×2240 PNG를 실제로 내려받아 이미지 배치와 텍스트를 확인했습니다.
- 사진 없이도 기본 아이콘으로 저장할 수 있습니다. 능력분석관은 사용자가 제공한 Gem으로 연결되며 자동 등급 판정 기능은 없습니다.
- 모바일 검증은 브라우저의 390px iframe으로 진행했습니다. 실제 iOS·Android 기기의 파일 저장 UI는 별도 확인 대상입니다.

## 홈 등록 안내 배너·팝업 검증

- 공통 헤더의 ROA / KR과 홈의 기존 RANGER ID 카드를 제거했습니다. ARCHIVE의 기존 등록증 배너와 직접 연결은 유지되는 것을 확인했습니다.
- 홈의 세계관 핵심 카드와 연표 사이에 등록 안내 배너를 배치했습니다. 데스크톱 및 390px·320px 모바일 iframe에서 배너와 두 안내 카드의 배치를 확인했습니다.
- 배너 클릭 시 팝업 열기, 닫기 버튼·Esc·바깥 클릭으로 닫기, 배너로 초점 복귀를 확인했습니다. native dialog로 뒤 화면의 조작을 제한하고, 열린 동안 배경 스크롤을 잠급니다.
- 능력분석관 링크가 기존 Gem 주소를 공유하고 새 탭으로 열리는 표기·속성을 확인했습니다. 등록증 카드 클릭으로 실제 제작 화면에 이동하는 것을 확인했습니다.
- 팝업 설명은 사용자가 요청한 이능력 창작·등급 지정과 등록증 제작 기능만 안내하며 기존 세계관 설정을 변경하지 않습니다.
