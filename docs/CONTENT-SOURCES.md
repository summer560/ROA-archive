# 콘텐츠 출처와 공개 범위

확인일: 2026-09-13.

1. 「ROA 설정집 정리」: 상세 설정 기준본.
2. 「roa 웹사이트 구성요소」: 공개 페이지 문구와 공개용 축약 연표.
3. 사이트 제작 요청 및 후속 수정: 메뉴, 세 조직 표어와 입장, 색상, 이미지 교체 및 준비 중 메뉴 범위. 후속 수정 요청을 원문보다 우선합니다.
4. 사용자 첨부 `ROA MAIN 2026.09.jpg`: 현재 홈 메인 일러스트. WebP로 압축했으며 다른 인물·배경·의상을 합성하지 않았습니다.

이번 요청의 첨부 파일은 이미지였고 별도 Markdown 파일은 없었습니다. 사용자가 지정한 원문과 공개용 구성 문서를 확인하여 작성했습니다. 사용자 요청에 따라 원본 문서의 주소와 문서 ID는 프로젝트에 포함하지 않습니다. 원문을 다시 확인해야 할 때는 사용자가 지정한 문서를 연결된 Drive에서 찾습니다.

문단을 묶거나 나누고 ‘했죠’를 ‘했습니다’로 바꾸어 편집했습니다. 숫자, 소속, 조직 권한, 등급과 타입의 구분을 임의로 바꾸지 않았습니다. 소제목·영문 라벨·홈 카피는 탐색을 위한 편집 요소이며 신규 설정이 아닙니다.

후속 요청에 따라 포탈 독립 항목과 이상현상 내부 규칙 도식·설명을 삭제했습니다. 연표는 가장 최근에 사용자가 지정한 1500s—1600s부터 1960s까지의 여덟 시기·사건명으로 변경했습니다. 이전의 1986·1991·1996 연도와 창설까지만 표시한다는 지시는 최신 연표 요청으로 대체됩니다. ROA 카드는 이능력자를 ‘인류 방위의 핵심 전력’, ORIGIN 카드는 ‘이 세계의 우월한 존재’로 보는 입장을 담습니다. ARCHIVE는 최신 요청에 따라 메인 일러스트 갤러리로 변경했으며, 캐릭터 메뉴의 ‘이 세계를 살아가는 사람들.’ 문구는 삭제했습니다. 이후 원문을 다시 읽더라도 이 삭제 항목들을 임의로 복원하지 않습니다.

캐릭터 개인사, STORY ONLY의 미래 사건, OPEN 후보, 원고 관리용 목차, 성적 설정의 상세 예시 등은 이번 공개 메뉴로 추가하지 않았습니다. 원본 문서 전체를 저장소에 복제하지 않으며 공개에 사용한 범위만 데이터로 관리합니다.

ARCHIVE에는 장비·앱·기관 자료·OOC 명령어의 실제 설정을 아직 게재하지 않았습니다. CHARACTERS도 공통 템플릿만 준비했습니다.

레퍼런스는 [Zenless Zone Zero](https://zenless.hoyoverse.com/ko-kr/main), [명일방주: 엔드필드](https://endfield.gryphline.com/ko-kr)입니다. 대형 타이포그래피, 비대칭 화면, 강한 대비, 포스터 같은 편집 방향을 참고했으며 로고·이미지·에셋·사이트 코드를 복제하지 않았습니다.

추가 수정: ALIEN 첫 화면의 한국어 제목과 소개 문단을 삭제했습니다. 영문 타이포그래피는 유지하며, 삭제한 두 문구를 메타데이터에도 사용하지 않습니다.

추가 수정: 관리국 카드 입장은 “이능력자를 관리해야 할 / 위험 요소로 봅니다.”의 두 줄로 표시합니다. 홈의 “ROA의 세계를 만나보세요.”는 삭제했습니다. 메인 이미지는 2026년 9월에 제공한 JPG의 구도와 내용을 유지하여 WebP로 변환했습니다.

최신 연표 편집: 기존 “분류와 통제”의 두 문장을 분류·국가 통제와 등록제·제도적 차별 항목으로 나눴습니다. 기존 창설 설명의 제도 정립 문장을 1960s 항목으로 옮겼으며, 나머지 설명은 유지했습니다. 새 세부 설정을 추가하지 않았습니다.

표기 수정: 사용자 요청으로 연표 연도 뒤의 물결표를 제거했습니다. 시기·사건·설명은 유지합니다.

갤러리 추가: 사용자 요청으로 현재 메인 일러스트의 확대 보기와 JPG 원본 다운로드를 공개했습니다. 원본을 수정하지 않고 파일 그대로 제공하며 인물 이름·소속·재사용 허가 등 새로운 설정이나 조건은 추가하지 않았습니다. 연도 크기 통일과 읽기 진행·목차 강조는 표시 방식만 변경합니다.

갤러리 표시 간소화: 사용자 요청으로 안내 문장, VISUAL GALLERY, 이미지 번호·제목·크기·포맷 표기를 삭제했습니다. 공개 제목은 GALLERY이며 이미지와 확대·다운로드 조작만 표시합니다. 원본 파일과 대체 텍스트는 유지합니다.

특수편성국 설정 정정: 사용자가 신설·개설 설정을 폐기했습니다. KOREA / 2026과 UNITED STATES / SDC의 작은 라벨을 삭제하고, 한국 지부 설명에서 신설·창설 시점을 암시하는 표현을 제거했습니다. 상설 특수운용부서와 기존 운용 방식은 유지합니다. 두 지부는 탭으로 읽도록 배치하되 원문 설정을 추가하지 않습니다.

공통 라벨 정리: 사용자 요청으로 하위 페이지 상단의 ROA / WORLD ARCHIVE 홈 링크를 제거했습니다. 홈의 브랜드 표시는 유지합니다.

SDC 운용 설명 수정: 사용자의 최신 설정에 따라 임시 대응부대 구성 중심의 설명을 사건의 특성과 필요에 맞는 레인저 배치로 변경했습니다. 해외 파견을 통한 세계 각지의 대응과 상위 등급 레인저의 단독 배치를 명시했습니다. 미국 지부 소속, 지정 인원 등록, 주로 Type 1 사건에 투입된다는 기존 설명은 유지합니다.
